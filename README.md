# Пожиратель душ

3D хоррор-игра в браузере. Помогай мальчику Мише, не дай ему стать чудовищем и переживи ночи.

**Играть:** https://lexysav1978.github.io/soul-eater/

## Что есть в игре

- Большая деревня, тёмный лес, кладбище, шахта и свой дом, где можно переждать ночь.
- Задания мальчика, крафт топора, кирки и лопаты, Камень души.
- Ночные скримеры, существа, которые выглядывают из-за углов, и силуэты.
- Полёт на самолёте и Туманный остров.
- Вторая часть: рай, головоломки и битва с Пожирателем душ.
- 13 скинов персонажа и три мультика: смешной, страшный и музыкальный.

## Управление

| Компьютер | Действие |
|---|---|
| WASD | ходить |
| Мышь | камера |
| Shift | бег |
| Пробел | прыжок |
| E / ЛКМ | действие |
| 1 2 3 / колесо | топор, кирка, лопата |
| C | крафт |
| F | фонарик |
| M | звук |
| Esc | пауза |

На телефоне: джойстик слева, камера справа, кнопки действий на экране. Лучше держать телефон горизонтально.

## Как запустить у себя

Открой `index.html` в браузере. При первом запуске нужен интернет: игра загружает библиотеку Three.js.
